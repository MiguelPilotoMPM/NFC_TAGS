# NFC_TAGS

Landing pages for my NFC stickers. Each tag lives in its own folder and is
served by GitHub Pages.

- Home: https://miguelpilotompm.github.io/NFC_TAGS/
- Cybersecurity: https://miguelpilotompm.github.io/NFC_TAGS/cybersecurity/

## Add a new tag
1. Create a folder, e.g. `my-new-tag/`
2. Put an `index.html` inside.
3. Link it from the home page.
4. URL: https://miguelpilotompm.github.io/NFC_TAGS/my-new-tag/
